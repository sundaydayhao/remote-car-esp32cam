# Remote Controller TODO

## 目标

`remote_controller` 是独立 ESP-IDF 项目，用 ESP32 模组实现一个手持遥控端：

- 连接 `car_controller` 创建的 Wi-Fi AP。
- 一个摇杆控制小车前进、后退、左转、右转和停止。
- 一个摇杆控制摄像头/云台上、下、左、右和居中。
- 4 寸 TFT 屏幕显示小车摄像头实时画面。
- 麦克风和扬声器与小车端进行语音互动。
- 遥控端失联、断网或摇杆回中时，小车必须能安全停车。
